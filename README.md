# 왕은 오지 않는다 — 885년 봉건 계약

서프랑크의 어느 백작령. **왕은 다섯 해 내내 오지 않습니다.**
땅을 떼어 주고 사람을 얻는 일을 다섯 번 반복하며 봉건제를 살아 보는
고등 세계사 수업용 브라우저 게임입니다.

**▶ 바로 하기 — https://king-never-comes.pages.dev/**

고등 세계사(김덕수) Ⅰ단원 3주제 「서유럽 봉건 사회」 pp.56~58 대응.

## 구조

885 프롤로그(문 3개) → **886~890 다섯 해 반복** → 891 결산

각 해는 협상(실시간) → 장원의 겨울 → 봄의 소집 → 방어 2파 → 여파로 돌아갑니다.
888년에 왕이 바뀌지만, 그래도 오지 않습니다.

## 이렇게 만들어져 있습니다

- **봉토는 카드가 아니라 9구획 지도입니다.** 준 땅은 그 봉신이 지키므로 약탈당하지 않습니다.
- **봉사에는 기한(1·2·3년)이 있습니다.** 만료되면 땅은 쥔 채 의무만 사라져 다시 계약해야 합니다.
- **세습을 인정하면 흥정이 끝납니다.** 대신 「주군의 권한」이 무너집니다.
- **신종례 4단계** — 신종(길게 누르기) → 평화의 입맞춤 → 충성 선서 → 봉토 수여
- **삼포제는 밭별 지력이 해를 넘어 누적됩니다.** 밀만 심으면 넷째 해에 돌밭이 됩니다.
- 농노 세 사람이 배치 변경에 즉시 반응하고, 에필로그에서 마지막으로 말합니다.

## 쓰는 법

`index.html` 하나만 있으면 됩니다. **인터넷 없이도 돌아갑니다.**
그림·소리·글꼴이 전부 파일 안에 들어 있어 외부로 나가는 요청이 하나도 없습니다. 학생 PC에 복사해 두고
브라우저로 열면 그대로 실행됩니다. (약 7.3MB · 크롬 권장)
